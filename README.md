# Poppins

Large models. Everyday hardware.

Poppins is an inference serving harness being built to run the largest practical
AI models on computers people can obtain or already own. It is designed for a
household sharing a model, a small group of developers, or one enthusiast
running several agents.

The target is consumer hardware: NVIDIA RTX 30-series GPUs, Intel CPUs, AMD
Strix Halo systems with 64 GB of system RAM or less, and MacBook Pro models
with 64 GB of unified memory. Apple silicon support will target the M3
generation first. The goal is useful serving under real memory limits, with
room for context and concurrent requests.

Poppins will include a browser interface served by the application on localhost.
Choose and configure models, manage client access, and monitor memory, queued
requests, and generation activity. The server keeps running when the browser
is closed and can serve applications and agents on your local network when
network access is enabled.

## Get Poppins

Poppins is in early development. There is no runnable release yet.

We expect to distribute ready-to-run builds. Download instructions, supported
hardware, and clone, build, and run commands will appear here as they become
available.

## Why Poppins

The name evokes a carpetbag with far more inside than its size suggests:
making room for large models within the limits of an ordinary machine.
